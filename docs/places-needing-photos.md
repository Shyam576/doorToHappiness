# Places that still need a photograph

No freely licensed photograph of these places exists on Wikimedia Commons, Unsplash, Pexels or Pixabay (searched in detail). On the site they currently show their dzongkhag's photograph with a visible "Photo: <District> district" tag, or a neutral panel where the district has no photo either (Pemagatshel).

To add a real photo (one you took or have written permission to use):

```
python3 scripts/add-place-photo.py PHOTO.jpg <dzongkhag-slug> "<Place name>" --author "Photographer name"
python3 scripts/add-place-photo.py PHOTO.jpg <dzongkhag-slug> --district --author "Photographer name"   # dzongkhag lead photo
```
It saves one high-quality WebP, updates the data and adds the credit to `/photo-credits`. Add `--dry-run` to preview.
